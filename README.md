# Social Engineering Awareness Simulator

A Python-based GUI application developed using Tkinter to simulate common social engineering attacks and improve cybersecurity awareness.

## Features

* Email Phishing Simulation
* Fake Tech Support Scam Simulation
* Impersonation (Call/Chat) Simulation
* Interactive User Decision Making
* Awareness Score Evaluation

## Technologies Used

* Python
* Tkinter

## Project Objective

The objective of this project is to educate users about common social engineering attacks by providing realistic attack scenarios and measuring user awareness through interactive simulations.
